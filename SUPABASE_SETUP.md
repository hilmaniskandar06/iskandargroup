# Supabase Setup - Iskandar Group

Project ini memakai `supabase-js` langsung seperti `sport kita`, bukan Prisma.
Jalankan SQL ini di Supabase SQL Editor untuk membuat struktur database baru.

## 1. Site Settings

Konten halaman disimpan fleksibel sebagai JSON di `site_settings`, mirip pola `sport kita`.

```sql
CREATE TABLE IF NOT EXISTS site_settings (
  id INTEGER PRIMARY KEY DEFAULT 1,
  data JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE site_settings ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Read site_settings publicly" ON site_settings;
CREATE POLICY "Read site_settings publicly"
ON site_settings FOR SELECT
USING (true);

INSERT INTO site_settings (id, data)
VALUES (1, '{}'::jsonb)
ON CONFLICT (id) DO NOTHING;
```

## 2. Business

```sql
CREATE TABLE IF NOT EXISTS business_categories (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  image_url TEXT,
  description TEXT,
  content TEXT,
  link_url TEXT,
  "order" INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS business_items (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  category_id INTEGER NOT NULL REFERENCES business_categories(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  image_url TEXT NOT NULL,
  link_url TEXT,
  "order" INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE business_categories ENABLE ROW LEVEL SECURITY;
ALTER TABLE business_items ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Read business_categories publicly" ON business_categories;
CREATE POLICY "Read business_categories publicly"
ON business_categories FOR SELECT
USING (true);

DROP POLICY IF EXISTS "Read business_items publicly" ON business_items;
CREATE POLICY "Read business_items publicly"
ON business_items FOR SELECT
USING (true);
```

## 4. News, CSR, Investor

```sql
CREATE TABLE IF NOT EXISTS news (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  excerpt TEXT,
  content TEXT,
  image_url TEXT,
  published BOOLEAN NOT NULL DEFAULT true,
  date TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  "order" INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS csr_programs (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  excerpt TEXT,
  content TEXT,
  image_url TEXT,
  category TEXT,
  date TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  "order" INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS investor_content (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  type TEXT NOT NULL DEFAULT 'report',
  file_url TEXT,
  content TEXT,
  year INTEGER,
  quarter INTEGER,
  published BOOLEAN NOT NULL DEFAULT true,
  "order" INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE news ENABLE ROW LEVEL SECURITY;
ALTER TABLE csr_programs ENABLE ROW LEVEL SECURITY;
ALTER TABLE investor_content ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Read published news publicly" ON news;
CREATE POLICY "Read published news publicly"
ON news FOR SELECT
USING (published = true);

DROP POLICY IF EXISTS "Read csr_programs publicly" ON csr_programs;
CREATE POLICY "Read csr_programs publicly"
ON csr_programs FOR SELECT
USING (true);

DROP POLICY IF EXISTS "Read published investor_content publicly" ON investor_content;
CREATE POLICY "Read published investor_content publicly"
ON investor_content FOR SELECT
USING (published = true);
```

## 5. Storage Bucket

Seperti `sport kita`, semua upload memakai satu bucket bernama `public`.

```sql
INSERT INTO storage.buckets (id, name, public)
VALUES ('public', 'public', true)
ON CONFLICT (id) DO NOTHING;

DROP POLICY IF EXISTS "Public read access to public bucket" ON storage.objects;
CREATE POLICY "Public read access to public bucket"
ON storage.objects FOR SELECT
USING (bucket_id = 'public');
```

## 6. Admin Login

Admin tidak lagi memakai tabel `AdminUser`. Admin dibuat di **Supabase Auth**.

Cara mudah:
- Buka `/admin/login`.
- Klik `Reset / Buat Admin Default`.
- App akan membuat atau mereset user Supabase Auth dari env:
  - `ADMIN_DEFAULT_EMAIL`
  - `ADMIN_DEFAULT_PASSWORD`

Pastikan `SUPABASE_SERVICE_ROLE_KEY` tersedia di `.env.local`, karena pembuatan admin memakai Admin API Supabase.
